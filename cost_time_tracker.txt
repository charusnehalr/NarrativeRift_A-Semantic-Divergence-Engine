Semantic Divergence Engine — Cost & Time Tracker
=================================================

Phase 2 — Proposition Chunking (Gemini)
----------------------------------------
- ~31 Gemini API calls (one per article)
- ~4 seconds sleep between each = ~2 minutes total
- Token usage: ~2000 tokens/article x 31 = ~62K tokens — well within 1M/day free tier
- Cost: $0 — all on Gemini free tier

Phase 3 — Embedding + ChromaDB (BGE-M3)
-----------------------------------------
Storing (one-time):
- ~31 articles x ~50 propositions avg = ~1550 total propositions to embed
- BGE-M3 on CPU: batch_size=4, ~4GB RAM required
- Estimated time: ~25-35 minutes for all 1550 propositions (one-time run, results persist to disk)
- ChromaDB storage: ~6MB on disk for 1550 x 1024-dim float vectors
- Cost: $0 — BGE-M3 is a local model, ChromaDB is local, no API calls

Retrieving (every query):
- Query text is embedded first: ~0.5-1 sec per query on CPU (single embed_single() call)
- ChromaDB similarity search over 1550 vectors: <100ms (HNSW index, very fast even on CPU)
- Total per query: ~1-2 seconds end-to-end
- Retrieval happens at pipeline runtime (contradiction detection) — not a one-time cost
- Cost: $0 — all local, no API calls

Phase 4 — Contradiction Detection (NLI)
-----------------------------------------
Tier 1 — DeBERTa (local):
- Runs on every cross-doc proposition pair that passes cosine threshold (≥0.75)
- ~1611 propositions × ~1-3 candidates each after filtering = ~500-2000 DeBERTa calls
- Each DeBERTa inference: ~0.5-1 sec on CPU
- Estimated time: ~15-30 minutes for full topic on CPU
- Cost: $0 — local model, no API

Tier 2 — Groq (LLM verification):
- ALL non-rejected pairs (DeBERTa score > 0.4) go to Groq for temporal/nuance filtering
- Groq batches 5 pairs per call → ~90 pairs / 5 = ~18 Groq calls
- Rate limit: 30 RPM, 14,400 RPD (free tier) — well within limits
- Sleep: 2 sec between calls → ~36 seconds total for Groq phase
- Cost: $0 — Groq free tier (llama-3.1-8b-instant)

Phase 5 — Graph Builder
-------------------------
- Input: contradiction_pairs.json (~37 pairs for topic_a)
- NetworkX graph construction: <1 second
- Louvain community detection: <1 second (fast even for large graphs)
- PyVis HTML generation: <5 seconds
- Total time: ~5-10 seconds (near instant)
- Output: graph_data.json (~55 nodes, ~37 edges) + graph.html (interactive viz)
- Cost: $0 — all local libraries (NetworkX, PyVis, python-louvain)
